## 🔧 Requisitos

### Para Linux/WSL:
- Sistema Linux (Ubuntu/Debian/Kali/Arch/Manjaro)
- Conexión a internet
- Permisos sudo
- Git instalado

### Para Windows:
- Windows 10/11 con WSL2 instalado
- O Git Bash + PowerShell

### Dependencias mínimas:
```bash
zsh git curl wget python3 python3-pip

⚡ Instalación Rápida
Opción 1: Linux/WSL (Recomendada)
# Clonar el repositorio
git clone https://github.com/tu-usuario/Mx-Emulator.git
cd Mx-Emulator

# Dar permisos y ejecutar
chmod +x setup.sh
./setup.sh

# Iniciar
mx

Opción 2: Windows (WSL)
# Abrir WSL y ejecutar:
wsl git clone https://github.com/tu-usuario/Mx-Emulator.git
wsl cd Mx-Emulator
wsl bash setup.sh
wsl mx

Opción 3: Windows Nativo
# Ejecutar el instalador
setup.bat

# Ejecutar el lanzador
Mx-Emulator.bat
